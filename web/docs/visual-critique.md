# Visual critique — 2026-08-23

Reviewed the arrival, generator, analyser, corpus, and pipeline surfaces at desktop width, plus the generator at 390×844.

- Kept the oversized headings deliberately overlapping the canvas: the overlap makes each surface read as a composition, not an admin dashboard.
- Kept the generator controls as a translucent edge panel and made the slider tracks wedge-shaped; no generic control-card grid was introduced.
- Used real generated SVGs and source photos as the visual material. The corpus field is generated from 240 extracted knowledge-base records and their matching thumbnail files.
- On mobile, the control panel becomes an internally scrollable lower tray so 44px navigation targets remain visible. The full action area remains reachable by touch rather than being removed.
- The analyser explicitly distinguishes cached verified samples from a real-photo upload; arbitrary uploads have no simulated fallback state.
